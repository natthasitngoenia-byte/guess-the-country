# Guess the country

เว็บ "หน้าคุณคล้ายคนประเทศไหน" ผู้ใช้อัปโหลดรูปหรือถ่ายจากกล้อง แล้วให้ AI (Google Gemini) บอกว่าลุคคล้ายคนประเทศไหน
พร้อมชื่อเล่น คำบรรยาย และจุดเด่น มีหลังบ้านสำหรับใส่ API Key

## เริ่มใช้งาน

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

```bash
npm start
```

- หน้าเว็บ: http://localhost:3000
- หลังบ้าน: http://localhost:3000/admin (ครั้งแรกให้ตั้งรหัสผ่านจากเครื่องนี้ แล้วใส่ Gemini API Key และเปิดใช้ AI)

## การทำงาน

1. เบราว์เซอร์ตรวจหาใบหน้าและครอปเฉพาะส่วนหน้า (ไลบรารี Human) พร้อมประเมินอายุและอารมณ์ในเครื่อง
2. ผู้ใช้ติ๊กยินยอม แล้วภาพหน้าที่ครอปแล้วถูกส่งผ่านเซิร์ฟเวอร์ไปที่ Gemini (เซิร์ฟเวอร์ไม่บันทึกภาพ)
3. Gemini เลือก 5 ประเทศพร้อมเปอร์เซ็นต์ เขียนชื่อเล่น คำบรรยาย และจุดเด่น
4. ถ้าโมเดลหลักไม่ว่าง เซิร์ฟเวอร์ลองซ้ำแล้วสลับไปใช้ `gemini-3.6-flash` และ `gemini-3.5-flash-lite`

## เอาขึ้นเว็บจริง (เช่น Render, Railway)

1. อัปโหลดโปรเจกต์ขึ้น GitHub (`data/` จะไม่ถูกอัปโหลด)
2. สร้าง Web Service: คำสั่ง start คือ `npm start` ไม่ต้องมีคำสั่ง build
3. ตั้งค่า environment:

| ชื่อ | ใช้ทำอะไร |
|---|---|
| `GEMINI_API_KEY` | Gemini API Key (แนะนำบนโฮสต์ฟรีที่ล้างไฟล์ตอนรีสตาร์ท จะได้ไม่ต้องใส่ใหม่ เปิดใช้ AI ให้อัตโนมัติ) |
| `ADMIN_PASSWORD` | รหัสผ่านหลังบ้าน (ต้องตั้ง เพราะตั้งรหัสครั้งแรกจากหน้าเว็บได้เฉพาะ localhost) |
| `TRUST_PROXY=1` | ให้การจำกัดจำนวนครั้งแยกผู้ใช้แต่ละคนได้ถูกต้องหลัง proxy |
| `DATA_DIR` | ชี้ไปดิสก์ถาวร ถ้าโฮสต์ล้างไฟล์ทุกครั้งที่ deploy (ไม่อย่างนั้น Key ที่บันทึกไว้จะหาย) |
| `PORT` | ส่วนใหญ่โฮสต์ตั้งให้เอง |

4. ถ้าไม่ได้ตั้ง `GEMINI_API_KEY` ให้เข้า `/admin` แล้วใส่ Key และเปิดใช้ AI

เว็บต้องเปิดผ่าน HTTPS (โฮสต์ส่วนใหญ่ให้มาอัตโนมัติ) ไม่อย่างนั้นเบราว์เซอร์จะไม่ยอมเปิดกล้อง
